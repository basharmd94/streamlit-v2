UtilityMart ERP flow map

Three servers, nine flows. Postgres names are the real column names on the HMBR server (da, PostgreSQL 9.4) and on the Fixit server (da). The Medusa shop is described in plain words. Built and tested locally on 2 Nov 2026; the shop's hooks do not exist yet.
